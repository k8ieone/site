## Update time!

This time I had the courage to admit that I am in fact not a web developer
nor do I want to be. So I ripped it off! 😋

Okay, well not completely. I still did a bit of work.

## Where is it actually from?

The original website's author is [TheEvilSkeleton](https://tesk.page/). I was
completely fascinated by the use of system accent colors and the site feels very
nice overall as well.

## Where's the work?

The work lies beneath the surface. The original site was templated using [Jekyll](https://jekyllrb.com/), my old *friend*.

It also wasn't created as a template (or theme, depending on which vocabulary you prefer to use),
instead it was created with only the author's site in mind. Kinda like my [old site](https://github.com/k8ieone/site/tree/hugo-old).

This weekend, {{< last_updated >}} that is, I dove deep into the original code
and adopted it to work as a [Hugo](https://gohugo.io/) theme! In doing so, I have
finally decoupled my website's content and code. Now the site repo only contains
my precious Markdown files which power this whole site.
Power of static site generators, baby!

As is tradition, the whole thing is FOSS. Links are at the end of the article.

The work still isn't done. While I adopted enough of the original site to make
my site work, there are still a few templates that need some work. Mainly a
portfolio template. Progress is being tracked [on Codeberg](https://codeberg.org/k8ie/tesk-hugo-port/issues/2).

Once I get portfolios ported, I can finally start using my site to show off some
of my projects!
